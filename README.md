
# SB Notes — C++ Study Notes Portal

A responsive study-material website for M.Sc Computer Science.

## Features

- Responsive design
- Dark modern interface
- Unit-wise PDF cards
- Search and unit filters
- PDF links
- About the author
- GitHub Pages compatible
- No backend or database required

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Project Structure

cpp-university-notes-portal/

├── app.js

└── pdfs/

## Add a PDF

1. Create a folder named `pdfs`.
2. Put your PDF inside it.
3. Open `data.js`.
4. Find the required unit.
5. Change its URL.

Example:

url: "pdfs/unit-1-cpp-notes.pdf"

Commit and push your changes.

## Run Locally

Open index.html in a browser.

For a better local development experience,
use the Live Server extension in VS Code.

## Deploy on GitHub Pages

1. Create a GitHub repository.
2. Upload all project files.
3. Open repository Settings.
4. Select Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select main branch.
7. Select / (root).
8. Save.

Your website will be published at:

https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
